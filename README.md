# VRCNeph

Windows desktop app for VRChat favorites, avatar and world search, friends, messages, activity, and an in-game overlay.

## Download

Download the current Windows EXE from the [latest GitHub release](https://github.com/TNephilim/VRCNeph/releases/latest). The EXE is intentionally published as a release asset, not stored in this repository.

The app source, build project, and detailed source README are in [Source Code](./Source%20Code/).
