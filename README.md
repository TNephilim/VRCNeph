# VRCNeph

Windows desktop app for VRChat favorites, search, friends, messages, and activity tracking.

## Features

- Manage avatar favorite groups
- Manage world favorite groups
- Sync VRChat favorites and keep local groups
- Search avatar databases
- Search and browse worlds
- View friend details, statuses, locations, and profiles
- Read VRChat messages and notifications
- Use the in-game overlay for avatars, worlds, friends, current info, and recent items
- Track recent player, world, and user activity
- Check deleted/private avatars and worlds
- Sort, copy, move, and clean up favorite groups
- Customize the app theme, panel opacity, and background effects
- Back up and restore app data

## Overlay

Open the in-game overlay with `F8` while VRCNeph is running. The overlay can be moved and resized, follows the app theme, and has settings for opacity, default panel, and keybind.
